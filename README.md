Metasploitable 2 Penetration Testing Lab
Overview
A practical penetration testing project using Kali Linux and Metasploit Framework in an isolated virtual lab.

Tools Used
Kali Linux
Metasploit Framework
Nmap
VMware Workstation
Project Objectives
Scan open ports and identify running services.
Explore vulnerabilities in a controlled environment.
Document penetration testing steps and results.
Lab Environment
The project uses Metasploitable 2 as an intentionally vulnerable target machine.

Screenshots
Screenshots documenting the penetration testing process are included in this repository.
